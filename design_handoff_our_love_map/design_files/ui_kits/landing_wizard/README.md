# Landing + Wizard — Light theme UI kit

The light-theme surface for **Our Love Map**: marketing landing page + the multi-step form wizard where one half of the couple builds the map.

- Background: `#FBF5F0` cream
- Primary CTA: coral `#F56C73`
- Headings: DM Serif Display (italic flourishes in primary)
- Body/UI: Plus Jakarta Sans

## Components
- `Navbar.jsx` — translucent cream nav with blur on scroll
- `Hero.jsx` — headline + primary CTA + illustrative map preview
- `FeatureGrid.jsx` — three-up features
- `Testimonial.jsx` — simple romantic quote card
- `Wizard.jsx` — 4-step form with progress dots and preview panel
- `Footer.jsx`
- `primitives.jsx` — Button, Input, Chip, Card

Open `index.html` for an interactive click-thru.
